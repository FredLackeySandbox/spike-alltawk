Who can add these

Only an identity holding a current owner or administrator role in this conversation can create a conversation-scoped emoji. Ordinary members can react with them but can't add new ones.

If your role changes, emoji you added stay; the check happens at creation time.

Reaction behaviour

  • · Reactions work like Slack's: click to add, click again to remove
  • · Each reaction links one identity, one emoji and one message
  • · Removing a reaction keeps the history rather than erasing it
  • · Only active participants who can see a message can react to it
